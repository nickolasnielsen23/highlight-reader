# Highlight Reader

A single web page for reading the highlights and notes you made on a Kobo e-reader, next to the book they came from.

**Open it:** https://nickolasnielsen23.github.io/highlight-reader/

1. Open the page. It starts with a short sample book so you can see how it works.
2. Click **Open your files…** and pick the book's `.annot` file, plus the book's `.epub` if you have it.
3. With the `.epub`, every highlight is marked in the text. Click a highlight on either side to jump to the other.
4. **Copy notes** copies all your highlights and notes as text, ready to paste into Notes, Docs or Obsidian.

**Where the files are:** connect the Kobo to a computer by USB. For books you added yourself, the `.annot` files are usually in the `Digital Editions/Annotations` folder on the Kobo. The `.epub` is wherever you copied the book.

**Privacy:** your files are read inside your own browser and never uploaded anywhere. The whole app is the one `index.html` file in this repo, and it also works if you download that file and open it directly.
